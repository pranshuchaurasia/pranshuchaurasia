## Selected work

### [Image Indexing and Retrieval with Qdrant](https://github.com/pranshuchaurasia/image-indexing-and-retrival-with-qdrant)

An image indexing and retrieval system that uses Qdrant with ColPali, ColQwen, VDR-2B-Multi-V1, and Jina Embeddings v4. The project supports scalable semantic search across large image datasets.

`Qdrant` `ColPali` `Multimodal Search` `Vector Database`

### [Low-Cost Humanoid Head Design](https://ieeexplore.ieee.org/abstract/document/10099206)

Developed two modular humanoid heads, Flat Affect and Symbolic, with a three-servo eye mechanism. The design achieved a 71.76% reduction in volume and 46.80% lower power use compared with traditional six-servo designs. EmotionNet was deployed on Jetson Nano for real-time facial analysis.

`Robotics` `Computer Vision` `Jetson Nano` `EmotionNet`

### [Automated Industrial Robots Simulation](https://ieeexplore.ieee.org/document/9545017)

Simulated automated industrial robots for cylinder liner production lines. The proposed system improved efficiency by 73.42% and reduced manufacturing time by 34.78% compared with manual production.

`Robotics` `Simulation` `Industrial Automation`
